# Fonts and icons

The frontend bundles Fraunces, Inter, and Source Serif 4 through the
`@fontsource-variable/fraunces`, `@fontsource-variable/inter`, and
`@fontsource-variable/source-serif-4` npm packages. Each font uses the SIL Open
Font License 1.1. See [Fraunces](Fraunces-OFL.txt), [Inter](Inter-OFL.txt), and
[Source Serif 4](Source-Serif-4-OFL.txt) for the full license texts.

Interface icons come from `@lucide/svelte` and are bundled locally as SVGs.
See the [Lucide license](Lucide-LICENSE.txt). The cookbook logo in
`static/icons/logo.svg` is covered by the project's MIT license.
