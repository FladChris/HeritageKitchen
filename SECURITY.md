# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability**. Include the affected version, steps to reproduce and
the impact you expect.

You will get a first answer within two weeks. Heritage Kitchen is a hobby
project, so fixes may take some time; you will be kept informed.

## Deployment notes

Heritage Kitchen is meant for private networks. Anyone who can reach an
instance can read its recipes, so keep it inside your home network or behind a
VPN and use HTTPS through a reverse proxy.
